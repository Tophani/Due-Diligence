Three separate status systems

Never merged into one colour. A complete submission is not a compliant organisation; an uploaded document is not an approved one.

1 · Requirement status (per question / document)

Not started Answered Document uploaded Under review Changes requested Approved N/A · reason given Provided by TracTrac

Teal = the vendor has done their part. Blue/green/amber = TracTrac's review decision.

2 · Submission completeness (per organisation)

Not started Defaulter · no documents Partial submission Submission complete

"Not started" shows before the deadline; "Defaulter" only after it, or earlier if the cycle is configured that way.

3 · Review & compliance outcome

Awaiting review Under review Information requested Compliant Conditionally compliant Non-compliant

Outcome is set by a reviewer only after evidence review ends. It never derives from upload counts.
